🧠 PRODUCTOS vs. SERVICIOS

Análisis Arquitectónico: Por qué DiagCentro Santa Fe necesita un esquema diferente

❌ MODELO ACTUAL: Todo es "Producto"

✅ MODELO PROPUESTO: Servicios con Inteligencia

🔥 LA DIFERENCIA CLAVE: PRODUCTOS vs. SERVICIOS CON TURNOS

PRODUCTOS (Pizzería, Tienda La Esquina): Cliente elige → Factura → Pago → Listo.
SERVICIOS CON TURNOS (DiagCentro, CentroMedicIntegral): Cliente solicita → AGENDA TURNO → Profesional ejecuta → Genera resultado → Factura → Entrega informe.

Sin turnos + profesionales + resultados: El agente NO puede operar la clínica. Solo puede listar precios como un catálogo muerto.

Con este esquema: El agente puede agendar turnos según disponibilidad real, asignar profesionales, verificar si estudios están listos, y enviar informes a pacientes. ESO es el valor de venta.

📊 Tablas Nuevas Requeridas

  • profesionales (especialidad, horarios)
  • turnos (agenda central del sistema)
  • estudios_realizados (PDFs, informes)
  • disponibilidad_equipos (opcional fase 2)

🔧 Campos Nuevos en productos

  • duracion_minutos (para bloques agenda)
  • requiere_turno BOOLEAN
  • requiere_profesional BOOLEAN
  • tipo_resultado (PDF, físico, digital)

🤖 Capacidades del Agente IA

  • Agendar turnos verificando disponibilidad
  • Asignar profesionales según especialidad
  • Consultar estado de estudios/informes
  • Facturar servicios realizados (no solo vendidos)
